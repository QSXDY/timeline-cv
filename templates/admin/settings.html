CDN 加速（腾讯 EdgeOne）

附件目录为 /static/uploads/**。下方两种加速方案任选其一，按需配置：

方案一：子域名只加速附件（推荐，零额外配置）

  1. 在 EdgeOne 添加一个子域名（如 cdn.yourdomain.com），源站类型选「源站域名/IP」，回源地址填部署本项目的服务器域名或 IP；
  2. 把该子域名填入上方「加速域名前缀」（如 https://cdn.yourdomain.com），并开启 CDN；
  3. 效果：仅图片、视频、头像等附件走 CDN；前台页面、后台、CSS/JS 仍由源站直出，无需任何排除规则。

方案二：主域名全站加速（需要配置排除规则）

  1. 把主域名接入 EdgeOne 全站加速，页面、后台、附件所有请求都经 CDN；
  2. 必须添加排除规则：EdgeOne 控制台 → 规则引擎 → 匹配 URL Path 前缀 /adminc → 操作选「节点缓存 TTL：不缓存」，否则后台登录与管理会被缓存导致异常；
  3. 建议同时让 HTML 动态页面不缓存（或开启智能加速），避免前台内容更新后不实时；
  4. 「加速域名前缀」填主域名或独立子域名均可，两种都需配置上述排除规则。

仅填域名或协议+域名，如 https://img.example.com；不带尾部斜杠。

EdgeOne 挂载说明

  1. 在腾讯云 EdgeOne 添加加速域名（如 cdn.yourdomain.com），源站类型选「源站域名/IP」，回源地址填部署本项目的服务器域名或 IP。
  2. 回源 Host 保持默认（加速域名回源到服务器同路径），这样 /static/uploads/** 会被 CDN 直接代理。
  3. 本项目 Docker 部署时将 ./data/uploads 挂载为 /app/static/uploads，源站即服务器上的真实附件目录。
  4. 首次访问回源拉取后由 CDN 缓存，图片/视频会自动带上 EdgeOne 的缓存与压缩能力。
